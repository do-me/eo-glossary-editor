First release of EO Glossary Editor: a desktop app for reviewing CEOS Earth observation glossary terms and sending one GitHub pull request per editing session.

- Search and filter terms by review team, class, and discussion status.
- Edit multiple terms in tabs, with WYSIWYG and Markdown editing, ready-made new-term skeletons, and protected required headings.
- Autosave locally, restore your workspace and zoom, and export/import portable sessions.
- Review rendered changes and source diffs; fetch main updates and resolve overlapping local changes explicitly.
- Authenticate with a personal access token, create a PR, and send later edits to the same PR.
- After submitting, see one persistent PR summary, the full contribution, and a separate view of edits not yet sent. Successful submission brings that summary into view.

### First use

The default glossary repository is `ceos-org/eo-glossary`. In Settings, expand **Use a personal access token** and sign in. A classic token needs `public_repo`; organization policies still apply. The optional GitHub App Device Flow requires maintainer registration and a public client ID; that ID is not bundled in this release. See [authentication setup](https://github.com/do-me/eo-glossary-editor/blob/v0.1.0/docs/GITHUB-SETUP.md).

The macOS packages are ad-hoc signed and not notarized. Windows installers are unsigned. Operating systems may require explicit approval for these first-release packages. Windows and Linux packages are built by CI; interactive testing has been performed on macOS. Personal-token commits and PRs were successfully tested by the maintainer. Device authorization and expiring-token refresh still need a live trial.

Existing local sessions are preserved when upgrading. The editor code is MIT licensed; bundled glossary material retains its upstream attribution and citations. See `LICENSE` and `NOTICE.md`.
